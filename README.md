# Pace

Rust-powered local API protection and rate limiting engine.

## Features

- Local in-memory rate limiting
- Sliding window / token bucket algorithms
- Shadow mode
- Multi-runtime SDKs
- Live telemetry streaming
- Rust-powered execution engine

## SDKs

- Node.js
- Python
- Rust
- Go

## Architecture

Request → SDK → Rust Engine → Decision → Telemetry
